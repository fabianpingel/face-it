Face it! – Arbeitsblatt B

Faltung von Hand  ·  Seite 1: So wird gerechnet

Ein Filter ist ein kleines Zahlengitter, der Kernel. Er wird über das Bild gelegt und liefert für jedes Feld eine neue Zahl. Auf Seite 2 rechnet ihr das für ein echtes Bild aus – hier steht erst einmal, wie das geht.

Der Kernel (3 × 3)

-1 0 1
-2 0 2
-1 0 1

Kernelzahlen sind cyan, Bildzahlen dunkelblau.

So rechnest du ein Feld aus

  1. Lege den Kernel so auf das Bild, dass seine Mitte auf deinem Feld liegt.
  2. Multipliziere jede Kernel-Zahl mit der Bildzahl, die darunter liegt.
  3. Addiere alle neun Ergebnisse.
  4. Schreibe den Betrag – also ohne Minuszeichen – in dein Feld.

Beispiel 1  ·  der Kernel liegt auf einer Kante

3 3 5
3 3 5
3 3 5

links dunkel (3), rechts hell (5)

×
-1 0 1
-2 0 2
-1 0 1

der Kernel

(-1 · 3) + (0 · 3) + (1 · 5)  =  (-3) + 0 + 5  =  2
(-2 · 3) + (0 · 3) + (2 · 5)  =  (-6) + 0 + 10  =  4
(-1 · 3) + (0 · 3) + (1 · 5)  =  (-3) + 0 + 5  =  2
Alle drei Zeilen addiert:  8  →  Betrag 8

In das Feld kommt also die 8.

Beispiel 2  ·  der Kernel liegt auf einer gleichmäßigen Fläche

4 4 4
4 4 4
4 4 4

überall dieselbe Helligkeit (4)

×
-1 0 1
-2 0 2
-1 0 1

derselbe Kernel

(-1 · 4) + (0 · 4) + (1 · 4)  =  (-4) + 0 + 4  =  0
(-2 · 4) + (0 · 4) + (2 · 4)  =  (-8) + 0 + 8  =  0
(-1 · 4) + (0 · 4) + (1 · 4)  =  (-4) + 0 + 4  =  0
Alle drei Zeilen addiert:  0  →  Betrag 0

In das Feld kommt also die 0.

Vergleicht die beiden Beispiele: dieselbe Rechnung, aber einmal kommt 8 heraus und einmal 0. Merkt euch das – auf Seite 2 werdet ihr beide Fälle wiedersehen.

Faltung von Hand  ·  Seite 2: Eure Aufgabe

Unten steht ein winziges Bild: 6 × 6 Helligkeitswerte. Damit man im Kopf rechnen kann, gehen die Werte hier nur von 0 (dunkel) bis 9 (hell). Jede Gruppe rechnet zwei Felder aus – genau so wie in den Beispielen auf Seite 1.

Das Bild (6 × 6)

ABCDEF
1 1 1 1 8 8 8
2 1 1 1 8 8 8
3 1 1 1 8 8 8
4 1 1 1 8 8 8
5 1 1 1 8 8 8
6 1 1 1 8 8 8

Der Kernel (3 × 3)

-1 0 1
-2 0 2
-1 0 1

Wer rechnet welche Felder?

Gruppe 11B   1A
Gruppe 21C   1D
Gruppe 32B   2A
Gruppe 42C   2D
Gruppe 53B   3A
Gruppe 63C   3D
Gruppe 74B   4A
Gruppe 84C   4D

Das Ergebnis (4 × 4) – hier eintragen

ABCD
